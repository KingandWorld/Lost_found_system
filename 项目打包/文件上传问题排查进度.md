## 代码层面修改（已完成，需要部署新 jar）

### 1. WebConfig.java — 新增文件系统资源映射

```java
// 文件: springboot/src/main/java/org/example/springboot/config/WebConfig.java
// 新增 @Value 注入:
@Value("${file.base-path:./files}")
private String fileBasePath;

// 新增方法:
@Override
public void addResourceHandlers(ResourceHandlerRegistry registry) {
    Path absolutePath = Paths.get(fileBasePath).toAbsolutePath().normalize();
    String fileLocation = "file:" + absolutePath.toString().replace("\\", "/");
    if (!fileLocation.endsWith("/")) {
        fileLocation += "/";
    }
    registry.addResourceHandler(
            "/img/**", "/file/**",           // 直接访问
            "/api/img/**", "/api/file/**"     // 前端拼接 /api 前缀的访问
    ).addResourceLocations(fileLocation);
}
```

## Nginx 配置演进记录

### 原始配置（134.175.83.214.conf）

有两个 `location ^~ /api/img/` 和 `location ^~ /api/file/`，用 `alias` 指向文件目录，但混用了 `try_files $uri =404`。

### 尝试过的修改

| 尝试 | 操作 | 结果 |
|------|------|------|
| 1 | 删除 `try_files $uri =404` | 还是 404 |
| 2 | 添加 `limit_except GET HEAD` | 上传接口返回 403（`limit_except` 与 `alias` 不兼容） |
| 3 | 删除 `/api/img/` 和 `/api/file/` 的 location，改走 Spring Boot | 返回 403（旧 jar 没有 `addResourceHandlers`） |
| 4 | 重写整个 Nginx 配置为干净版本 | **最后一次操作，需要验证** |

### 最后一次 Nginx 配置（已写入服务器）

```nginx
# HTTP 强制跳转 HTTPS
server {
    listen 80 default_server;
    server_name www.zang1357.chat;
    location /.well-known/ { root /www/wwwroot/java_node_ssl; allow all; }
    location / { return 301 https://$host$request_uri; }
}

server {
    listen 443 ssl default_server;
    http2 on;
    server_name www.zang1357.chat;
    root /www/wwwroot/lost-found/frontend/dist;
    index index.html index.htm;

    # SSL 证书...
    client_max_body_size 20m;

    # 所有 /api/ 请求透传 Spring Boot
    location /api/ {
        proxy_pass http://127.0.0.1:1235;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_connect_timeout 30s;
        proxy_read_timeout 60s;
    }

    # 前端 SPA
    location / {
        try_files $uri $uri/ /index.html;
    }

    location ~* (\.user.ini|\.htaccess|\.git|\.svn|\.env|node_modules) { return 404; }
}
```

**核心思路**: `/api/` 下所有请求（上传 + 图片展示）全部透传给 Spring Boot 处理，不再在 Nginx 层区分 `/api/img/` 和 `/api/file/`。
